# GS8 Triple 0.7.0 — без Root и Shizuku

Приложение для GAC GS8 Gen2 (Android 9). Версия 0.7.0 полностью убирает Shizuku, Root, AIDL-сервис и выполнение shell-команд.

## Планируемая раскладка экрана 1920×968

- Слева: Музыка, x=0..400 (400 px).
- Центр: Навигатор, x=400..1160 (760 px).
- Справа: Rutube или выбранное приложение, x=1160..1920 (760 px).

## Как работает версия 0.7.0

Для запуска каждого выбранного приложения используется публичный Android API `ActivityOptions.setLaunchBounds(Rect)`. Каждое приложение запускается в отдельной задаче с запрошенными границами окна.

В приложении нет:
- Shizuku и Shizuku Provider;
- Root / `su`;
- ADB-команд и shell;
- `dumpsys`, `am task resize` и ручного поиска Task ID.

**Важное ограничение:** Android официально указывает, что `setLaunchBounds()` игнорируется, если устройство не объявляет `FEATURE_FREEFORM_WINDOW_MANAGEMENT` (или PiP), либо дисплей не поддерживает такие окна. Поэтому успешный вызов запуска ещё не доказывает, что прошивка GAC реально расположит три окна по заданным координатам. Это нужно проверить на магнитоле. Документация: https://developer.android.com/reference/android/app/ActivityOptions#setLaunchBounds(android.graphics.Rect)

## Сборка через GitHub Actions

1. Распакуй архив.
2. В существующем GitHub-репозитории замени файлы проекта содержимым папки `GS8Triple` (включая `.github`). Не загружай ZIP как один файл.
3. Сделай Commit changes.
4. Открой Actions → Build GS8 Triple APK и дождись зелёной отметки.
5. Внизу успешного запуска скачай артефакт `GS8-Triple-0.7.0-no-Shizuku`.
6. Распакуй артефакт и установи `app-debug.apk` на магнитолу.

Workflow использует Android SDK, уже предустановленный на GitHub-hosted runner, и не запускает `android-actions/setup-android`, чтобы избежать прежней ошибки `sdkmanager`.

## Проверка на магнитоле

1. Открой GS8 Triple.
2. Нажми «Проверить поддержку Freeform» и сфотографируй результат.
3. Выбери три разных приложения.
4. Нажми «Разложить три окна».
5. Проверь, появились ли три окна и соблюдены ли размеры/порядок.

Если окна не разложились, пришли фото диагностики и экрана. Приложение пока не проверено на реальной прошивке GAC; не считаем точное размещение подтверждённым до теста.
